# Week 3 - JavaScript Interactive Webpage

Interactive frontend built with HTML, CSS and plain JavaScript.

## Implemented
- Mobile navigation toggle
- Dynamic hero interaction message
- Preview state change/reset
- Expand/collapse service details
- Scroll-to-top control
- Client-side contact form validation
- DOM manipulation and event listeners
- Smooth scrolling

## Run
Open index.html in a modern browser. No framework or build step is required.
