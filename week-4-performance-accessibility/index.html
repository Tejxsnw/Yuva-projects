Accessibility

Built for different ways of browsing

Semantic landmarks and headings provide a clear document structure. Visible focus styles support keyboard users, while the skip link lets users bypass repeated navigation.

  • Descriptive links and headings
  • Visible keyboard focus indicators
  • Form controls with explicit labels
  • ARIA used only where it adds useful information

Quick accessibility check

Keyboard: Tab through every interactive element.

Screen reader: Navigate by headings and landmarks.

Images: Provide useful alt text when images convey meaning.

Contrast: Keep text and controls visually distinguishable.
