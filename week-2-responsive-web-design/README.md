# Week 2 - Responsive Web Design

Responsive landing page created from scratch for the internship task.

## Demonstrated
- Semantic HTML5
- CSS Grid and Flexbox
- Fluid typography with clamp()
- Flexible containers and responsive cards
- Responsive CSS device visual
- Media queries at 900px, 620px and 400px
- Desktop, tablet and mobile layouts

## Test
Use Chrome DevTools Device Toolbar or resize the browser to verify each breakpoint.
